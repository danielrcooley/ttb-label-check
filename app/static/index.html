      About this tool

      What it does

      It reads the text on label images with an on-device text-recognition model, compares what it read with what the application says, checks the government warning statement word for word against 27 CFR 16.21, and shows you exactly where on the label it found each item. It works in a few seconds and makes no calls to outside services.

      What it does not do

      • It does not approve or reject applications. Every result is a recommendation for a compliance agent.
      • It does not store images, application data, or results. Refreshing the page clears everything.
      • It does not check permits, formulas, class/type validity, age statements or laboratory tolerances.
      • It does not measure physical type size or bold type from a photograph reliably; those items are marked for you to confirm.

      How it decides

      Match means the label says the same thing, allowing for letter case and accents. Needs review means it is close but you should look, which is usually OCR noise. Mismatch and Not found mean the label disagrees or the item could not be read. For the warning statement, only an exact match passes.

      Accessibility

      Built with the U.S. Web Design System. Target: WCAG 2.1 AA and Section 508. Every status is shown as an icon, a word and a color, never a color alone. The page works with keyboard only, at 200% zoom, and in Windows High Contrast Mode. If something does not work for you, please say so in the project repository.
