# Consult 008: how to measure bold type in the warning statement

## What the product does today (D-044)
27 CFR 16.22(a)(2) requires "GOVERNMENT WARNING" in capitals and bold and the rest of the statement
not in bold. OCR gives text and boxes, not weight. The product measures each OCR line's stroke
thickness on the array the engine read: greyscale, Otsu, the minority class is ink, the L2
distance transform over the ink, stroke = 4 x the mean distance, divided by the crop height
(`stroke_ratio`). A line carrying the heading is measured as heading and remainder separately,
splitting the box at the heading's share of the CHARACTERS (`m.end() / len(text)`), the head
crop trimmed to 0.95 of that point and the tail crop starting at 1.08 of it (`measure_line`).
`type_weight_ratio` compares the heading with the rest of its own line, or, when the heading
stands alone, its stroke in pixels (weight x the canonical box's y-extent) with the median of the
other lines'. `type_weight_status`: ratio >= 1.15 gives Match on both format rows ("heading bold",
"remainder not bold"); <= 1.05 gives Needs review on both; between is inconclusive (Not checked);
too small or faint is Not checked with the reason. Gates: box height >= 24 px and stroke >= 3.8 px.
Every line of every read (upright, the rotation retry's losing reads, rescue reads) is measured.

     1	"""Type weight from pixels: is a line of print bold?
     2	
     3	OCR gives text and boxes, not weight. What can be measured is the thickness of the ink strokes in
     4	a line's box relative to the type height: bold faces run roughly 1.4 to 1.8 times heavier than
     5	their regular weight, and a heading set in bold next to a body set regular shows as a clear step.
     6	The measurement is a heuristic: it is reported as a ratio and the warning report decides (D-044),
     7	and only a confident reading becomes a finding; small or low-contrast print is "not measured".
     8	
     9	Method per crop: greyscale, Otsu threshold, the minority class is ink; the distance transform over
    10	the ink averages about a quarter of the stroke width, so stroke = 4 * mean distance; the result is
    11	divided by the crop height (the type size, ascenders to descenders as the detector boxed it).
    12	"""
    13	
    14	from __future__ import annotations
    15	
    16	import re
    17	from dataclasses import dataclass
    18	
    19	import cv2
    20	import numpy as np
    21	
    22	# Tiny crops gain nothing from OpenCV's thread pool, and on a two-vCPU host that pool contends with the
    23	# OCR engine's threads (one intra-op thread per worker). Keep OpenCV single-threaded in this process.
    24	cv2.setNumThreads(1)
    25	
    26	_ANCHOR = re.compile(r"g\s*o\s*v\s*e\s*r\s*n\s*m\s*e\s*n\s*t\s*w\s*a\s*r\s*n\s*i\s*n\s*g\s*:?", re.I)
    27	MIN_HEIGHT = 24  # px of box height: below this the strokes are a pixel or two and the ratio is noise
    28	MIN_WIDTH = 24
    29	MIN_STROKE = 3.8  # px: thinner strokes are quantized (a bold heading over a regular body measures 1.0 at 3 px)
    30	
    31	
    32	@dataclass(frozen=True)
    33	class LineWeight:
    34	    weight: float | None  # whole line
    35	    head: float | None  # the "GOVERNMENT WARNING" part, when the line carries it
    36	    tail: float | None  # the rest of that same line
    37	
    38	
    39	def stroke_ratio(gray: np.ndarray) -> float | None:
    40	    """Stroke width of the print in a greyscale crop, as a fraction of the crop height; None when
    41	    the crop is too small or holds no clean ink."""
    42	    if gray.ndim != 2:
    43	        return None
    44	    h, w = gray.shape
    45	    if h < MIN_HEIGHT or w < MIN_WIDTH:
    46	        return None
    47	    _, bw = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    48	    ink = bw == 0
    49	    if ink.mean() > 0.5:
    50	        ink = ~ink  # light print on a dark ground
    51	    frac = float(ink.mean())
    52	    if frac < 0.03 or frac > 0.6:
    53	        return None
    54	    dt = cv2.distanceTransform(ink.astype(np.uint8), cv2.DIST_L2, 5)
    55	    vals = dt[ink]
    56	    if vals.size < 40:
    57	        return None
    58	    stroke = 4.0 * float(vals.mean())  # overstates strokes under ~3 px, evenly for heading and body
    59	    if stroke < MIN_STROKE:
    60	        return None
    61	    ratio = float(stroke / float(h))
    62	    if ratio > 0.6:  # a "stroke" over half the type height is a solid block or a bar code, not print
    63	        return None
    64	    return ratio
    65	
    66	
    67	def _crop(arr: np.ndarray, x0: float, y0: float, x1: float, y1: float, pad: int = 2) -> np.ndarray | None:
    68	    h, w = arr.shape[:2]
    69	    xa, ya = max(0, int(x0) - pad), max(0, int(y0) - pad)
    70	    xb, yb = min(w, int(x1) + pad), min(h, int(y1) + pad)
    71	    if xb - xa < MIN_WIDTH or yb - ya < MIN_HEIGHT:
    72	        return None
    73	    part = arr[ya:yb, xa:xb]
    74	    return cv2.cvtColor(part, cv2.COLOR_RGB2GRAY) if part.ndim == 3 else part
    75	
    76	
    77	def to_gray(arr: np.ndarray) -> np.ndarray:
    78	    """Greyscale once per read; measure_line accepts either the colour array or this."""
    79	    return cv2.cvtColor(arr, cv2.COLOR_RGB2GRAY) if arr.ndim == 3 else arr

    82	def measure_line(arr: np.ndarray, box: object, text: str) -> LineWeight:

   262	    """Heading stroke weight over body stroke weight, and what it was measured against. The sound
   263	    comparison is the heading against the rest of its own line: same size, same face, same box, so
   264	    the normalization cancels (real labels: a semibold heading reads 1.15, a bold one 1.24, all-bold

   266	    with the median of the other lines' (the box heights differ, so ratios would not). None when
   267	    the print was too small or faint to measure."""

   270	        return None

   274	    def height(ln: OcrLine) -> float:

   276	        return max(1.0, y1 - y0)

   279	    if len(others) < 2:

    50	    # coordinates). The warning rescue looks there first; it costs nothing.

    55	# once more upright at bounded full resolution).

    59	def _to_lines(
    60	    raw: list[RawLine],
    61	    dec: DecodedImage,
    62	    index: int,
    63	    degrees: int,
    64	    rot_w: int,
    65	    rot_h: int,
    66	    arr: np.ndarray | None = None,
    67	) -> list[OcrLine]:
    68	    """Canonical lines from a read, with the type weight of each line measured on the array the
    69	    engine read (``arr``), so the warning report can judge bold type without the pixels."""

    71	    gray = to_gray(arr) if arr is not None and raw else None
    72	    for r in raw:
    73	        lw = measure_line(gray, r.box, r.text) if gray is not None else None

    75	            OcrLine(
    76	                image_index=index,
    77	                text=r.text,

   113	async def process_image(
   114	    up: Upload, index: int, settings: Settings, run: Runner, *, queue_ms: int = 0
   115	) -> ProcessedImage:
   116	    """Decode one upload and read it on the given slot, retrying sideways orientations when the
   117	    first read is poor (the one failure mode the engine does not recover on its own). The reads
   118	    that lose the retry are kept as alternates rather than thrown away."""
   119	    dec = decode_image(
   120	        up.data, max_pixels=settings.max_image_pixels, max_side=settings.ocr_max_side, filename=up.filename
   121	    )
   122	    t0 = time.perf_counter()
   123	    raw = await run(dec.array)
   124	    h, w = dec.array.shape[:2]
   125	    reads: dict[int, tuple[list[RawLine], int, int, np.ndarray]] = {0: (raw, w, h, dec.array)}
   126	    chosen = 0
   127	    mean = float(np.mean([r.confidence for r in raw])) if raw else 0.0
   128	    if mean < settings.ocr_low_conf_retry or len(raw) < settings.ocr_min_lines_retry:
   129	        for degrees in (90, 270):
   130	            rot = rotate_array(dec.array, degrees)
   131	            raw2 = await run(rot)
   132	            reads[degrees] = (raw2, rot.shape[1], rot.shape[0], rot)
   133	            if _read_score(raw2) > _read_score(reads[chosen][0]) * 1.15:
   134	                chosen = degrees
   135	    ocr_ms = int((time.perf_counter() - t0) * 1000)
   136	    raw_best, rw, rh, arr_best = reads[chosen]
   137	    lines = _to_lines(raw_best, dec, index, chosen, rw, rh, arr_best)
   138	    alternates = {d: _to_lines(r, dec, index, d, w2, h2, a2) for d, (r, w2, h2, a2) in reads.items() if d != chosen}
   139	    info = ImageInfo(
   140	        index=index,
   141	        filename=up.filename,
   142	        width=dec.width,
   143	        height=dec.height,
   144	        format=dec.format,
   145	        rotated_degrees=chosen,
   146	        quality=_quality(raw_best),
   147	    )
   148	    return ProcessedImage(info=info, lines=lines, queue_ms=queue_ms, ocr_ms=ocr_ms, alternates=alternates)
   149

   151	async def process_images(
   152	    uploads: list[Upload], settings: Settings, pool: OcrPool, *, interactive: bool
   153	) -> list[ProcessedImage]:
   154	    """Interactive: each image takes its own slot so a front+back pair costs one image-time, and a
   155	    statement that went unread gets one more round of reads (``_rescue_warning``).
   156	    Batch: one slot is held for all the images of the request, so it can never be refused halfway,
   157	    and every image is read exactly once. The batch screen reads images before it knows which
   158	    application they belong to, so a front label, which carries no statement by design, must not
   159	    trigger re-reads (measured: they cut batch throughput to a quarter, docs/LOADTEST.md)."""
   160	    if interactive:
   161	
   162	        async def one(i: int, u: Upload) -> ProcessedImage:
   163	            async with pool.slot(interactive=True) as (run, queue_ms):
   164	                return await process_image(u, i, settings, run, queue_ms=queue_ms)
   165	
   166	        processed = list(await asyncio.gather(*(one(i, u) for i, u in enumerate(uploads))))
   167	        if settings.warning_rescue:
   168	            await _rescue_warning(uploads, processed, settings, pool)
   169	        return processed
   170	    async with pool.slot(interactive=False) as (run, queue_ms):
   171	        return [await process_image(u, i, settings, run, queue_ms=queue_ms) for i, u in enumerate(uploads)]
   172	
   173	
   174	async def _rescue_warning(
   175	    uploads: list[Upload], processed: list[ProcessedImage], settings: Settings, pool: OcrPool
   176	) -> None:
   177	    """Two layouts hide the statement from the ordinary read: printed sideways along the edge of a
   178	    small label that otherwise reads perfectly upright (so the low-confidence retry never fires),
   179	    and printed in small type on large artwork (unreadable once the image is scaled to the working
   180	    size). When no usable statement was found (none, or a span far from the required text): first
   181	    look at the orientations the rotation retry already read, then run ONE round of extra reads in
   182	    parallel on their own slots, at most one per worker: turned 270 then 90 degrees and, for large
   183	    artwork, once more at bounded full resolution (that one first when the heading was seen but the
   184	    body was not). One round keeps the interactive path inside its time budget whatever the number
   185	    of workers, and the round is the same for the same input and configuration. The best span that
   186	    beats the upright read is kept. A read that cannot get a slot is refused like any other
   187	    interactive read (BusyError, HTTP 429), never skipped silently."""
   188	    upright = find_warning([ln for p in processed for ln in p.lines])
   189	    floor = upright.similarity if upright else 0.0
   190	    if floor >= settings.warning_rescue_below:
   191	        return
   192	    for p in processed:  # free: what the retry read and did not keep
   193	        for lines in p.alternates.values():
   194	            span = find_warning(lines)
   195	            if span is not None and span.similarity > floor:
   196	                _adopt(p, span)
   197	                floor = span.similarity
   198	    if floor >= settings.warning_rescue_below:
   199	        return
   200	    plans: list[list[RescueRead]] = []
   201	    for up, p in zip(uploads, processed, strict=True):
   202	        if not p.info.quality.readable:
   203	            continue  # nothing legible at all; turning it will not help
   204	        seen = {p.info.rotated_degrees, *p.alternates}
   205	        # 270 first: it unrolls a statement printed up a label's right edge, reading bottom to top,
   206	        # which is how three of the four such labels in the real sample print it (docs/EVAL_REAL.md).
   207	        turns: list[RescueRead] = [(p, up, d) for d in (270, 90) if d not in seen]
   208	        side = min(settings.warning_rescue_max_side, max(p.info.width, p.info.height))
   209	        full: list[RescueRead] = [(p, up, None)] if side > settings.ocr_max_side else []
   210	        heading_seen = find_warning(p.lines) is not None
   211	        plans.append(full + turns if heading_seen else turns + full)
   212	    # The first read of every image before any second read, so a front+back pair shares the round.
   213	    depth = max((len(plan) for plan in plans), default=0)
   214	    ordered = [plan[k] for k in range(depth) for plan in plans if k < len(plan)]
   215	    reads = ordered[: pool.workers]
   216	    if not reads:
   217	        return
   218	    spans = await asyncio.gather(*(_rescue_read(p, up, degrees, settings, pool) for p, up, degrees in reads))
   219	    best: dict[int, WarningSpan] = {}
   220	    for (p, _, _), span in zip(reads, spans, strict=True):
   221	        idx = p.info.index
   222	        if span is not None and span.similarity > floor and (idx not in best or span.similarity > best[idx].similarity):
   223	            best[idx] = span
   224	    for p in processed:
   225	        if p.info.index in best:
   226	            _adopt(p, best[p.info.index])
   227	
   228	
   229	def _adopt(p: ProcessedImage, span: WarningSpan) -> None:
   230	    """Add a rescued statement to an image's lines and drop what the kept read had in the same
   231	    places: the same strip of print read in another orientation is garbage, and two readings of
   232	    one region must not both be there."""
   233	    p.lines = [*(ln for ln in p.lines if not any(_same_place(ln, s) for s in span.lines)), *span.lines]
   234	
   235	
   236	def _same_place(a: OcrLine, b: OcrLine) -> bool:
   237	    """True when the boxes cover mostly the same area (more than half of the smaller one)."""
   238	    ax = [pt[0] for pt in a.box]
   239	    ay = [pt[1] for pt in a.box]
   240	    bx = [pt[0] for pt in b.box]
   241	    by = [pt[1] for pt in b.box]
   242	    inter_w = max(0.0, min(max(ax), max(bx)) - max(min(ax), min(bx)))
   243	    inter_h = max(0.0, min(max(ay), max(by)) - max(min(ay), min(by)))
   244	    area_a = max(1.0, (max(ax) - min(ax)) * (max(ay) - min(ay)))
   245	    area_b = max(1.0, (max(bx) - min(bx)) * (max(by) - min(by)))
   246	    return inter_w * inter_h / min(area_a, area_b) > 0.5
   247	
   248	
   249	async def _rescue_read(
   250	    p: ProcessedImage, up: Upload, degrees: int | None, settings: Settings, pool: OcrPool
   251	) -> WarningSpan | None:
   252	    async with pool.slot(interactive=True) as (run, queue_ms):
   253	        t0 = time.perf_counter()
   254	        if degrees is None:
   255	            side = min(settings.warning_rescue_max_side, max(p.info.width, p.info.height))
   256	            dec = decode_image(up.data, max_pixels=settings.max_image_pixels, max_side=side, filename=up.filename)
   257	            arr, turn = dec.array, 0
   258	        else:
   259	            dec = decode_image(
   260	                up.data, max_pixels=settings.max_image_pixels, max_side=settings.ocr_max_side, filename=up.filename
   261	            )
   262	            arr, turn = rotate_array(dec.array, degrees), degrees
   263	        raw = await run(arr)
   264	        lines = _to_lines(raw, dec, p.info.index, turn, arr.shape[1], arr.shape[0], arr)
   265	        p.queue_ms += queue_ms
   266	        p.ocr_ms += int((time.perf_counter() - t0) * 1000)
   267	    return find_warning(lines)

    31	class ImageError(Exception):
    32	    def __init__(self, code: str, message: str, hint: str | None = None) -> None:
    33	        super().__init__(message)
    34	        self.code, self.message, self.hint = code, message, hint

    37	def sniff_format(data: bytes) -> str | None:
    38	    for sig, fmt in _SIGNATURES:
    39	        if data.startswith(sig):
    40	            return fmt
    41	    if data[:4] == b"RIFF" and data[8:12] == b"WEBP":
    42	        return "webp"
    43	    return None

    46	@dataclass
    47	class DecodedImage:
    48	    array: np.ndarray  # RGB uint8, downscaled working copy
    49	    width: int  # canonical (oriented original) width
    50	    height: int  # canonical height
    51	    scale: float  # working = canonical * scale
    52	    format: str
    53	    filename: str | None
    54	
    55	
    56	def decode_image(data: bytes, *, max_pixels: int, max_side: int, filename: str | None = None) -> DecodedImage:
    57	    fmt = sniff_format(data)
    58	    if fmt is None:
    59	        head = data[:5]
    60	        if head.startswith(b"%PDF"):
    61	            raise ImageError(
    62	                "unsupported_format",
    63	                "PDF files are not supported.",
    64	                "Export the label artwork as PNG or JPEG and upload that.",
    65	            )
    66	        if head.lstrip().startswith(b"<"):
    67	            raise ImageError(
    68	                "unsupported_format",
    69	                "SVG and other text-based files are not supported.",
    70	                "Upload PNG, JPEG, GIF, WebP, TIFF or BMP.",
    71	            )
    72	        if data[4:12] in (b"ftypheic", b"ftypheix", b"ftypmif1", b"ftypmsf1"):
    73	            raise ImageError(
    74	                "unsupported_format",
    75	                "HEIC photos are not supported.",
    76	                "On iPhone, share the photo as JPEG, or set Camera > Formats to Most Compatible.",
    77	            )
    78	        raise ImageError(
    79	            "unsupported_format", "This file is not a supported image.", "Upload PNG, JPEG, GIF, WebP, TIFF or BMP."
    80	        )
    81	    try:
    82	        im = Image.open(BytesIO(data))
    83	        w, h = im.size
    84	        if w * h > max_pixels:
    85	            raise ImageError(
    86	                "image_too_large",
    87	                f"This image is {w} x {h} pixels, above the {max_pixels // 1_000_000} megapixel limit.",
    88	                "Resize the image below the limit and upload it again.",
    89	            )
    90	        if fmt == "gif":
    91	            im.seek(0)
    92	        # The canonical size is the oriented original, fixed here from the header before any
    93	        # reduced-size decode can change im.size. EXIF orientations 5-8 swap width and height.
    94	        swapped = im.getexif().get(0x0112, 1) in (5, 6, 7, 8)
    95	        canon_w, canon_h = (h, w) if swapped else (w, h)
    96	        if fmt == "jpeg" and min(w, h) >= 2 * max_side:
    97	            # libjpeg decodes at 1/2, 1/4 or 1/8 size while keeping both sides at or above max_side:
    98	            # a 12 MP phone photo costs a quarter of the memory and time. Coordinates are unaffected
    99	            # because scale is computed against the canonical size recorded above.
   100	            im.draft("RGB", (max_side, max_side))
   101	        im = ImageOps.exif_transpose(im) or im
   102	        im = im.convert("RGB")
   103	    except ImageError:
   104	        raise
   105	    except Exception as exc:  # Pillow raises many types for corrupt data
   106	        raise ImageError(
   107	            "corrupt_image",
   108	            "This image could not be decoded.",
   109	            "The file may be truncated or corrupt. Re-export it and try again.",
   110	        ) from exc
   111	    scale = min(1.0, max_side / max(canon_w, canon_h))
   112	    target = (max(1, round(canon_w * scale)), max(1, round(canon_h * scale)))
   113	    if im.size != target:
   114	        im = im.resize(target, Image.LANCZOS)
   115	    return DecodedImage(array=np.asarray(im), width=canon_w, height=canon_h, scale=scale, format=fmt, filename=filename)

   118	def rotate_array(arr: np.ndarray, degrees: int) -> np.ndarray:
   119	    """Rotate counter-clockwise by 90, 180 or 270 degrees (numpy convention)."""
   120	    k = {0: 0, 90: 1, 180: 2, 270: 3}[degrees]
   121	    return np.ascontiguousarray(np.rot90(arr, k)) if k else arr
   122	
   123	
   124	def unrotate_point(x: float, y: float, degrees: int, rot_w: int, rot_h: int) -> tuple[float, float]:
   125	    """Map a point in a rotated array back to the unrotated array's coordinates.
   126	
   127	    rot_w, rot_h are the rotated array's width and height. Derived from numpy.rot90 semantics:
   128	    k=1 (90 CCW): rotated (x, y) came from original (rot_h - y, x)
   129	    k=2 (180):    original (rot_w - x, rot_h - y)
   130	    k=3 (270 CCW = 90 CW): original (y, rot_w - x)
   131	    """
   132	    if degrees == 0:
   133	        return x, y
   134	    if degrees == 90:
   135	        return rot_h - y, x
   136	    if degrees == 180:
   137	        return rot_w - x, rot_h - y
   138	    if degrees == 270:
   139	        return y, rot_w - x
   140	    raise ValueError(degrees)
   141	
   142	
   143	def to_canonical(
   144	    box: np.ndarray | Sequence[Sequence[float]], *, scale: float, degrees: int, rot_w: int, rot_h: int
   145	) -> Quad:
   146	    """OCR box (4 points, in the working array as fed to OCR, possibly rotated) -> canonical quad."""
   147	    pts = []
   148	    for x, y in box:
   149	        ux, uy = unrotate_point(float(x), float(y), degrees, rot_w, rot_h)
   150	        pts.append((round(ux / scale, 1), round(uy / scale, 1)))
   151	    return (pts[0], pts[1], pts[2], pts[3])

===== EXCERPT: docs/LIMITS.md (item 1) =====
1. **Bold type is measured, not read.** 27 CFR 16.22 requires "GOVERNMENT WARNING" in bold and the
   rest not in bold. The tool measures the thickness of the ink strokes in the heading and in the
   body of the statement, relative to the type height (`app/pipeline/typeface.py`, decision D-044).
   A heading clearly heavier than the body is a Match on both counts; heading and body of the same
   weight is Needs review on both, because the measurement cannot tell a heading that is not bold
   from a statement that is all bold; a small difference is inconclusive. Print under about 24
   pixels tall or with strokes under 3.5 pixels at the working size is "Not checked" with that
   reason, which covers most registry artwork of small labels; the synthetic corpus and large
   artwork measure well. Never a failure: it is a measurement of print, and the crop is shown.
2. **Physical type size and characters per inch are not assessed.** They need a known scale.

    41	def column_stroke(gray: np.ndarray) -> np.ndarray:
    42	    """Per-column stroke estimate (4 x mean distance over the ink pixels of that column); NaN where
    43	    the column carries no ink."""
    44	    _, bw = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    45	    ink = bw == 0
    46	    if ink.mean() > 0.5:
    47	        ink = ~ink
    48	    dt = cv2.distanceTransform(ink.astype(np.uint8), cv2.DIST_L2, 5)
    49	    out = np.full(gray.shape[1], np.nan)
    50	    for c in range(gray.shape[1]):
    51	        col = dt[:, c][ink[:, c]]
    52	        if col.size:
    53	            out[c] = 4.0 * float(col.mean())
    54	    return out

    57	def change_point(prof: np.ndarray, lo: float = 0.12, hi: float = 0.7) -> int | None:
    58	    """Single step change point of a noisy profile: the split minimizing the within-segment sum of
    59	    squares, searched between lo and hi of the width. NaN columns are ignored."""
    60	    n = prof.size
    61	    valid = ~np.isnan(prof)
    62	    if valid.sum() < 20:
    63	        return None
    64	    v = np.where(valid, prof, 0.0)
    65	    cnt = np.cumsum(valid.astype(float))
    66	    s1 = np.cumsum(v)
    67	    s2 = np.cumsum(v * v)
    68	    best, best_s = None, np.inf
    69	    for s in range(int(n * lo), int(n * hi)):
    70	        nl, nr = cnt[s - 1], cnt[-1] - cnt[s - 1]
    71	        if nl < 8 or nr < 8:
    72	            continue
    73	        sl, sr = s1[s - 1], s1[-1] - s1[s - 1]
    74	        ql, qr = s2[s - 1], s2[-1] - s2[s - 1]
    75	        cost = (ql - sl * sl / nl) + (qr - sr * sr / nr)
    76	        if cost < best_s:
    77	            best, best_s = s, cost
    78	    return best

1. **The estimator.**

   Sound enough as a same-line ranking heuristic above the gate, not as an absolute 3–8 px stroke-width measurement. The \(4\times\) identity is exact only for ideal parallel strips; real glyph topology and Otsu segmentation violate it (`app/pipeline/typeface.py:39-64`).

   - Thin strokes: biased high from pixel quantization; anti-aliasing and JPEG can move the Otsu boundary by a large fraction of the stroke.
   - Dense lowercase: counters and terminals bias low; junctions bias high. The net is text-dependent, usually lower than simple capitals.
   - Capitals: generally closer to the ideal-strip estimate and relatively high versus lowercase, creating a case/glyph-composition confound.
   - Textured ground: fine texture usually biases low by adding many one-pixel “ink” samples; broad dark texture biases high. The direction is uncontrolled once the minority-class assumption missegments the ground (`app/pipeline/typeface.py:47-58`).

   Do not switch immediately. Robustness per engineering hour:

   1. Current distance transform, with split/validity fixes.
   2. Ink area ÷ skeleton length, after removing small components; best alternative to shadow-test.
   3. Morphological-opening granulometry; simple but scale-quantized and structuring-element dependent.
   4. Stroke-width transform; potentially sounder, but costly and sensitive to weak/JPEG-corrupted gradients.
   5. Horizontal-run mode; cheapest but confounds glyph width, horizontal bars, orientation, and counters.

   The present bar tests validate only ideal strips, not those biases (`tests/unit/test_typeface.py:9-28`).

2. **The split (P3).**

   Prefer a semantic pixel boundary: find the connected-component/projection gap immediately after the printed colon, within a character-derived search window; use the stroke change point to score or refine candidate gaps. A free change-point optimizer always returns *something* when enough pixels exist—there is currently no “valid step” test (`split_experiment.py:57-78`). The all-bold sample’s spurious 0.13 split demonstrates this (`split_synth.log:6`).

   Require a positive left-to-right stroke drop, minimum ink on both sides, material SSE improvement/effect size, and ratio stability over nearby candidate splits. A character-share fallback may support Needs review, but must never produce a heading Match by itself.

   - `(1)` belongs wholly to the tail; otherwise its thin numeral can manufacture the transition.
   - Keep the colon in the heading, but exclude it with the margin.
   - Title case is fine empirically: 0.33 prior versus 0.37 pixel boundary (`split_synth.log:5`).
   - OCR-added/dropped characters damage only the prior; the pixel gap should remain authoritative.
   - A different face can create a stroke step without a weight change; treat that result as weaker evidence.
   - Two-line `GOVERNMENT` / `WARNING:` is currently located but cannot be weight-measured because the weight path requires both words on one line (`app/pipeline/warning.py:54-67`, `app/pipeline/warning.py:268-270`; `app/pipeline/typeface.py:26,96-106`). Measure both heading fragments and compare them with later body lines.
   - If only one body word follows the heading, the tail is too short; use compatible later body lines or abstain.

   The 0.8–1.6 prior window covers the observed synthetic boundaries, but clamp it to valid geometry and minimum segment content. A 0.15×type-height margin is a reasonable starting value; require at least one estimated stroke width and shrink it only when both resulting samples remain adequate (`split_experiment.py:140-148`).

3. **Geometry (P2).**

   The short **edge** of the raw OCR quadrilateral—not the short axis-aligned extent—is the type height for upright, 90°/270° retry, vertical-strip, and full-resolution-rescue reads. Compute opposing edge lengths or rectify the quad. The current min/max extents become wrong for skewed text, and the current x-axis split cannot handle a vertical line (`app/pipeline/typeface.py:87-105`; `app/pipeline/warning.py:75-91`). The malformed vertical cases in the experiment confirm this (`split_real.log:52,71,108`).

   Canonical stroke pixels should be `stroke_read / dec.scale`; that is geometrically scale-safe because canonical boxes use the same division (`app/pipeline/images.py:48-52,143-150`). Working-size versus rescue comparisons will still have rasterization error from Lanczos/Otsu, so validate tolerance rather than expect equality (`app/pipeline/images.py:111-115`, `app/services.py:254-264`). Using the unpadded box height as denominator corrects the present documentation/code mismatch, although padding can still alter which pixels enter the stroke estimate (`app/pipeline/typeface.py:67-74,90-94`).

   `_adopt` appends every rescued-span line and removes only kept-read lines overlapping those lines; non-overlapping kept lines remain (`app/services.py:229-246`). Thus the adopted span itself is single-read, but a later `find_warning` can form a hybrid span from rescued and retained lines. Preserve canonical stroke and type height per line—or pin the final span to one read—because `OcrLine` currently records neither source read nor scale (`app/schemas.py:64-74`).

4. **The matrix (P4–P6).**

   “Remainder not bold” cannot be asserted from this relative measurement. Extra-bold over bold is indistinguishable from bold over regular. P4’s `Not checked` is therefore correct; the current dual Match is unsafe (`app/pipeline/warning.py:303-310`).

   An absolute “body ratio below X means regular” gate is not defensible without broad, manually labelled font/weight calibration. Font design, capitalization, counters, box fit, Otsu, and resampling all move `stroke/type-height`. An unusually heavy body may justify Needs review, never Match or failure (`AGENTS.md:20-22`).

   P5’s ±25% size tolerance is too wide: an equal-weight heading 25% larger can generate a 1.25 stroke-pixel ratio and cross a 1.15 threshold solely from size. Require roughly ±10%, or normalize stroke by a validated type-height estimate. Real examples already combine 17–22% size differences with ratios of 1.33–1.39 (`split_real.log:7,84`).

   Provisionally use **1.20 for clearly heavier and retain 1.05 for same weight**, widening the inconclusive band to 1.05–1.20. After the corrected split, clean synthetic positives are 1.24–1.29, blurred positives only 1.16, and the sole all-bold negative is 1.00 (`split_synth.log:1-22`). Calling 1.16 Match leaves essentially no noise margin; do not raise the same-weight boundary until there are more all-bold, regular/regular, and bold/bold negatives.

5. **Validation.**

   D-045 must freeze the algorithm, corpus revision, font assets, thresholds, validity test, orientation handling, and exact denominators. Publish machine-readable rows, not only percentages.

   - Synthetic: counts and ratio distributions for regular/regular, bold/regular, bold/bold, extra-bold/bold, different faces, different sizes, title case, two-line headings, short tails, blur, JPEG, low contrast, scaling, and texture.
   - For every condition: eligible, measured, gap-split, change-point-split, fallback, rejected by each gate, Match, Needs review, and Not checked.
   - Report manual-boundary error, change-point effect/SSE improvement, raw and canonical stroke, type height, size ratio, head/body ratio, and classification.
   - Real: all 150 records and the 148 located warnings as counts; stratify same-line, standalone, split-heading, vertical, retry, rescue, measurable, and every abstention reason. Manually label a review subset for heading bold/body regular; approval alone is not pixel-level ground truth.
   - A false alarm is a bold-generated Needs review on a manually confirmed compliant approved label. Not checked is an abstention and must be reported separately. Also report unsafe false Matches on planted noncompliant labels.

   Honest summary: **“The heuristic detects a clear relative stroke increase in sufficiently large, comparable print and flags absence of that increase; it often abstains and cannot verify that the body itself is regular.”**

   Current evidence is inconsistent:

   - D-044 says 34 measurable/29 heavier/5 inconclusive/16 small, while `EVAL_REAL` reports about 64 heavier and 84 unmeasured-or-inconclusive among 148 located warnings (`docs/DECISIONS.md:D-044`; `docs/EVAL_REAL.md`, type-weight rows).
   - The real script is not the production pipeline: it performs one upright read, silently omits no-span images, and iterates images rather than records (`split_experiment.py:81-88,156-167`). Its log contains decode errors, vertical-axis failures, and a crop failure (`split_real.log:49,52,71,81,108,117`).

   - One all-bold negative is insufficient to validate either operating point.

6. **Tests.**

   Add these in order:

   - Bundled proportional regular/bold font: assert the recovered colon boundary and bold/regular ratio against known rendered coordinates.
   - Same proportional font, all bold: both rows Needs review; never a heading or body Match.
   - Extra-bold heading over bold body: heading may Match, body must remain Not checked.
   - Parameterized blur/JPEG/low-contrast/downscale tests for both bold/regular and all-bold.
   - Textured, gradient, inverted, and border-touching grounds: abstain rather than produce an unsafe Match.
   - `(1)` and the colon remain on opposite sides of the split.
   - OCR text with inserted/dropped characters but unchanged pixels yields the same pixel boundary/status.
   - Title-case heading and mixed-case body exercise glyph-composition bias.
   - Different heading/body faces cannot Match unless the configured evidence rule is satisfied.
   - `GOVERNMENT` / `WARNING: (1) ...` on two lines measures both heading fragments.
   - Heading plus only one body word uses later body lines or abstains.

   - `_adopt` hybrid retained/rescued lines preserve per-line scale/source or are rejected.

1. **The estimator.**

   Sound enough as a same-line ranking heuristic above the gate, not as an absolute 3–8 px stroke-width measurement. The \(4\times\) identity is exact only for ideal parallel strips; real glyph topology and Otsu segmentation violate it (`app/pipeline/typeface.py:39-64`).

   - Thin strokes: biased high from pixel quantization; anti-aliasing and JPEG can move the Otsu boundary by a large fraction of the stroke.
   - Dense lowercase: counters and terminals bias low; junctions bias high. The net is text-dependent, usually lower than simple capitals.
   - Capitals: generally closer to the ideal-strip estimate and relatively high versus lowercase, creating a case/glyph-composition confound.
   - Textured ground: fine texture usually biases low by adding many one-pixel “ink” samples; broad dark texture biases high. The direction is uncontrolled once the minority-class assumption missegments the ground (`app/pipeline/typeface.py:47-58`).

   Do not switch immediately. Robustness per engineering hour:

   1. Current distance transform, with split/validity fixes.
   2. Ink area ÷ skeleton length, after removing small components; best alternative to shadow-test.
   3. Morphological-opening granulometry; simple but scale-quantized and structuring-element dependent.
   4. Stroke-width transform; potentially sounder, but costly and sensitive to weak/JPEG-corrupted gradients.
   5. Horizontal-run mode; cheapest but confounds glyph width, horizontal bars, orientation, and counters.

   The present bar tests validate only ideal strips, not those biases (`tests/unit/test_typeface.py:9-28`).

2. **The split (P3).**

   Prefer a semantic pixel boundary: find the connected-component/projection gap immediately after the printed colon, within a character-derived search window; use the stroke change point to score or refine candidate gaps. A free change-point optimizer always returns *something* when enough pixels exist—there is currently no “valid step” test (`split_experiment.py:57-78`). The all-bold sample’s spurious 0.13 split demonstrates this (`split_synth.log:6`).

   Require a positive left-to-right stroke drop, minimum ink on both sides, material SSE improvement/effect size, and ratio stability over nearby candidate splits. A character-share fallback may support Needs review, but must never produce a heading Match by itself.

   - `(1)` belongs wholly to the tail; otherwise its thin numeral can manufacture the transition.
   - Keep the colon in the heading, but exclude it with the margin.
   - Title case is fine empirically: 0.33 prior versus 0.37 pixel boundary (`split_synth.log:5`).
   - OCR-added/dropped characters damage only the prior; the pixel gap should remain authoritative.
   - A different face can create a stroke step without a weight change; treat that result as weaker evidence.
   - Two-line `GOVERNMENT` / `WARNING:` is currently located but cannot be weight-measured because the weight path requires both words on one line (`app/pipeline/warning.py:54-67`, `app/pipeline/warning.py:268-270`; `app/pipeline/typeface.py:26,96-106`). Measure both heading fragments and compare them with later body lines.
   - If only one body word follows the heading, the tail is too short; use compatible later body lines or abstain.

   The 0.8–1.6 prior window covers the observed synthetic boundaries, but clamp it to valid geometry and minimum segment content. A 0.15×type-height margin is a reasonable starting value; require at least one estimated stroke width and shrink it only when both resulting samples remain adequate (`split_experiment.py:140-148`).

3. **Geometry (P2).**

   The short **edge** of the raw OCR quadrilateral—not the short axis-aligned extent—is the type height for upright, 90°/270° retry, vertical-strip, and full-resolution-rescue reads. Compute opposing edge lengths or rectify the quad. The current min/max extents become wrong for skewed text, and the current x-axis split cannot handle a vertical line (`app/pipeline/typeface.py:87-105`; `app/pipeline/warning.py:75-91`). The malformed vertical cases in the experiment confirm this (`split_real.log:52,71,108`).

   Canonical stroke pixels should be `stroke_read / dec.scale`; that is geometrically scale-safe because canonical boxes use the same division (`app/pipeline/images.py:48-52,143-150`). Working-size versus rescue comparisons will still have rasterization error from Lanczos/Otsu, so validate tolerance rather than expect equality (`app/pipeline/images.py:111-115`, `app/services.py:254-264`). Using the unpadded box height as denominator corrects the present documentation/code mismatch, although padding can still alter which pixels enter the stroke estimate (`app/pipeline/typeface.py:67-74,90-94`).

   `_adopt` appends every rescued-span line and removes only kept-read lines overlapping those lines; non-overlapping kept lines remain (`app/services.py:229-246`). Thus the adopted span itself is single-read, but a later `find_warning` can form a hybrid span from rescued and retained lines. Preserve canonical stroke and type height per line—or pin the final span to one read—because `OcrLine` currently records neither source read nor scale (`app/schemas.py:64-74`).

4. **The matrix (P4–P6).**

   “Remainder not bold” cannot be asserted from this relative measurement. Extra-bold over bold is indistinguishable from bold over regular. P4’s `Not checked` is therefore correct; the current dual Match is unsafe (`app/pipeline/warning.py:303-310`).

   An absolute “body ratio below X means regular” gate is not defensible without broad, manually labelled font/weight calibration. Font design, capitalization, counters, box fit, Otsu, and resampling all move `stroke/type-height`. An unusually heavy body may justify Needs review, never Match or failure (`AGENTS.md:20-22`).

   P5’s ±25% size tolerance is too wide: an equal-weight heading 25% larger can generate a 1.25 stroke-pixel ratio and cross a 1.15 threshold solely from size. Require roughly ±10%, or normalize stroke by a validated type-height estimate. Real examples already combine 17–22% size differences with ratios of 1.33–1.39 (`split_real.log:7,84`).

   Provisionally use **1.20 for clearly heavier and retain 1.05 for same weight**, widening the inconclusive band to 1.05–1.20. After the corrected split, clean synthetic positives are 1.24–1.29, blurred positives only 1.16, and the sole all-bold negative is 1.00 (`split_synth.log:1-22`). Calling 1.16 Match leaves essentially no noise margin; do not raise the same-weight boundary until there are more all-bold, regular/regular, and bold/bold negatives.
