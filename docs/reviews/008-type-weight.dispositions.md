# Dispositions for consult 008 (how to measure bold type)

Each answer in `008-type-weight.response.md` was weighed against the builder's measurements on both
corpora (the request carries them) before the method was changed. The product decisions are D-045.

| # | Answer | Disposition |
|---|---|---|
| 1 | The distance-transform estimator is sound as a same-line ranking heuristic above the gate, not as an absolute measurement; keep it, with the split and validity fixes, ahead of granulometry, the stroke width transform or run lengths | **Accepted.** Kept. The biases named (thin strokes high, lowercase low, capitals high, texture uncontrolled) are the reason the comparison stays within one line and the report never asserts the body's own weight (4). |
| 2 | Split at the word gap after the colon, with the stroke change point as the score, not a free change point; a valid step, minimum content on both sides; the character-share fallback may support Needs review but never a Match; "(1)" belongs to the tail; OCR text errors damage only the prior; measure both fragments of a two-line heading | **Accepted, one part partially.** `measure_line` looks for runs of empty columns between 0.9 and 1.6 times the character estimate, takes the gap with the largest stroke drop across it, and when nothing drops (one weight throughout) the gap nearest the typographic estimate (a quarter wider than the character share); margins of 0.15 type heights on each side; without a gap the character share is the boundary and `type_weight_status` turns a heavier reading on that basis into Not checked ("boundary uncertain"), never a Match. The gap before "(1)" wins on a bold heading because the numeral is regular. Two-line headings: the line opening with "WARNING:" is measured as heading and remainder (`heading_match`); the "GOVERNMENT" line alone is not measured (partial). Pinned by the real-face tests in `test_typeface.py`. |
| 3 | The type height is the quadrilateral's short edge, not the axis-aligned extent; rectify the quad; canonical stroke = stroke / scale; validate tolerance between scales; `_adopt` can form hybrid spans, so keep per-line canonical values | **Accepted.** `rectify` warps the box to an upright rectangle (long edge along x); stroke and type height are divided by the decode scale and carried on each line (`stroke_px`, `type_px`), so a hybrid span compares in one unit. Pinned by `test_rotated_and_vertical_lines_measure_like_the_upright_one`. |
| 4 | "Remainder not bold" cannot be asserted; no absolute body gate; standalone size tolerance about 10 percent; 1.20 for clearly heavier, 1.05 for same weight | **Accepted.** All four. Settings default 1.20; `SIZE_TOLERANCE` 0.10; the body row is Not checked when the heading is heavier, Needs review when the weights agree. |
| 5 | Freeze the algorithm and thresholds in D-045; publish counts per basis and abstention reason; manually label a subset; the honest one-sentence summary | **Partially.** D-045 freezes the method, gates and thresholds; `evaluate_real.py` emits rows per outcome (heavier, same weight, inconclusive, not measured with the reason) over all 150 records, and EVAL.md the synthetic outcomes; the summary sentence is in LIMITS. A manually labelled subset of the approved labels for heading-bold / body-regular is deferred (time before submission) and stated as such in LIMITS: approval is the only ground truth used, so "no false alarm on approved labels" is the claim, not "no miss". |
| 6 | Tests in order: real proportional face (bold/regular, all bold, extra-bold/bold), blur/JPEG/downscale, textured grounds, "(1)" and colon sides, OCR text noise, title case, different faces, two-line heading, one-word tail, rotations, working vs full resolution, hybrid spans, size tolerance, padding | **Partially.** Added: bold over regular, all bold and all regular in a real face (skipped where no face is installed); OCR text with dropped and added characters; rotation and vertical boxing; the padding denominator; the size tolerance either side of the limit; the character-share fallback never matching. Deferred: blur/JPEG/texture parameterisation, a two-line heading, a one-word tail, working-size against full-resolution parity, hybrid spans. |
| 7 | Risks: size-only false matches (tighten), hallucinated transitions (gap first, no fallback Match), min/max geometry (rectify), hybrid or unmeasured spans and arrays held longer (measure per read before adoption), reduced coverage (correct), 1.15 too permissive (1.20), a failed change point must not erase same-weight evidence | **Accepted.** Each is handled as listed above; the same-weight evidence survives without a gap because the fallback may still say Needs review. Coverage is reported honestly in the evaluations. |
